# v3.8.0 — Galeria de Fotos georreferenciadas (MVP)

**Data:** 2026-05-12
**Origem:** Pedido do CEO — central de fotos com carimbo GPS + data + endereço, reutilizáveis em Laudos / VTO / Propostas, com envio direto via WhatsApp e Telegram.

## O que entra (MVP enxuto)

### Backend
- Migration **`galeria_fotos`** — tabela com: tenant_id, user_id, user_nome, mime, arquivo_b64 (longtext), legenda, lat/lng/altitude/accuracy, endereco_reverso, capturada_em, tags, obra_id, criada_em
- Service **`src/integrations/galeria.ts`** — CRUD: listarFotos, buscarFotoComB64, criarFoto, apagarFoto, atualizarFoto
- Endpoints REST em `src/server.ts`:
  - `GET  /api/galeria` (lista, sem base64)
  - `GET  /api/galeria/:id/arquivo` (binário pra preview)
  - `POST /api/galeria` (upload da foto carimbada)
  - `PUT  /api/galeria/:id` (atualiza legenda/tags/obra_id)
  - `DELETE /api/galeria/:id`
  - `POST /api/galeria/:id/enviar` (canal: 'whatsapp'|'telegram', destinatario, caption)

### Frontend
- **Aba "📷 Galeria"** no menu principal (entre Loteamentos e Proposta)
- Botão **"📷 Tirar Foto"** — usa `<input type="file" accept="image/*" capture="environment">` que abre câmera nativa em mobile
- **Captura automática de:**
  - GPS (lat/lng/altitude/accuracy) via `navigator.geolocation`
  - Endereço reverso via **Nominatim** (OpenStreetMap, grátis e sem chave)
  - Timestamp
- **Carimbo aplicado client-side via Canvas:**
  - Faixa preta semi-transparente no rodapé da imagem
  - Linhas: coordenadas, endereço, data/hora, usuário + Romatec
  - Limita imagem a 1920px no maior eixo (economiza banda)
- **Grid de fotos** com cards (preview, legenda, GPS, endereço, data, ações)
- **Ações por foto**: enviar WhatsApp (📱 WA), enviar Telegram (✈️ TG), apagar (🗑)

### Integrações
- **WhatsApp**: reutiliza `whatsapp.sendImage()` (Z-API) com data URI da foto carimbada
- **Telegram**: chamada direta ao Bot API `sendPhoto` via multipart com `form-data`
