**Data:** 2026-05-27

**Versão alvo:** v3.31.0

## Resumo

Permite upload de **planta individual por quadra** em 3 formatos (DXF, DWG, PDF), substituindo (opcionalmente) o varredor do mapa completo do loteamento. Quando o técnico abre uma quadra, o sistema lê **apenas o arquivo daquela quadra** — performance melhorada, menos sujeito a erro.

Implementação foco: **backend completo** (migrations, storage, parser DXF, endpoints, multer) + **frontend POC** (chips DXF/DWG/PDF + botão "📎 Anexar planta" + modal de upload) por quadra na tela de Loteamento Detalhe.

## Princípios honrados

- ✅ Migration **TS idempotente** (padrão do repo, sem .sql files standalone).
- ✅ Validação manual (Zod não existe no repo).
- ✅ Parser DXF como **dependência opcional** (`dxf-parser` em `optionalDependencies`) com fallback graceful — se não instalado, `parse_status='manual'`.
- ✅ Storage filesystem com **hash SHA-256** + **backup automático** ao substituir arquivo anterior (`_backup_{timestamp}.{ext}`).
- ✅ Validação de **magic bytes** (`%PDF-`, `0\nSECTION`, `AC10XX`) antes de gravar.
- ✅ Multer **memoryStorage** com fileFilter por field + extensão + mime.
- ✅ Endpoints reutilizam prefixo `/api/loteamentos/*` (sem prefixo novo).
- ✅ Background parse não-bloqueante do DXF após upload.

## Endpoints

```
POST   /api/loteamentos/:lotId/quadras/:quadraId/planta/upload          (requireAuth)
       multipart/form-data com fields: dxf? dwg? pdf?
       → { ok, resultados: [{ formato, status, size_bytes?, hash?, detalhe? }] }

GET    /api/loteamentos/:lotId/quadras/:quadraId/planta                 (requireAuth)
       → metadados completos da row + parse_status

GET    /api/loteamentos/:lotId/quadras/:quadraId/planta/:formato/download
       → stream do arquivo (DXF/DWG/PDF) com Content-Disposition

DELETE /api/loteamentos/:lotId/quadras/:quadraId/planta/:formato
       → remove o formato (faz backup) + limpa colunas no DB

POST   /api/loteamentos/:lotId/quadras/:quadraId/planta/parse
       → força reparse do DXF (idempotente)

GET    /api/loteamentos/:lotId/quadras/:quadraId/planta/lotes-extraidos
       → { parse_status, num_lotes, lotes: [{ lote_numero, frente_m, fundo_m, l_dir_m, l_esq_m, area_m2, vertices_xy }] }
```

## Storage

Hierarquia: `./storage/loteamentos/{lotId}/quadras/{quadraId}/planta.{dxf|dwg|pdf}`. Override via `STORAGE_ROOT` env. Backup automático ao substituir: `_backup_{ISO_timestamp}.{ext}`.

## Tabela criada

```sql
loteamento_quadras_plantas (
  id INT PK,
  quadra_id INT NOT NULL UNIQUE,    -- 1:1 com quadra
  loteamento_id INT NOT NULL,
  {dxf,dwg,pdf}_{filename,path,size_bytes,uploaded_at,hash_sha256},
  num_lotes_detectados INT,
  perimetro_quadra_m, area_total_quadra_m2 DECIMAL,
  lotes_extraidos_json MEDIUMTEXT,
  parsed_at TIMESTAMP,
  parse_status ENUM('pendente','sucesso','erro','manual'),
  parse_error TEXT,
  uploaded_by_user_id INT,
  created_at, updated_at, deleted_at TIMESTAMP NULL,
  INDEX idx_loteamento, idx_parse_status, idx_deleted
)

ALTER loteamento_quadras ADD tem_planta_individual TINYINT(1) DEFAULT 0;
```
